# Beta Apps

{% hint style="success" %}
These applications are available exclusively to **SFT Holders** and **Verified Members**, enabling them to explore and provide feedback on cutting-edge functionalities before their public release
{% endhint %}

***

**Accessing Beta Apps**

1. Log into your Ofero.me account with a verified profile.
2. Navigate to **Beta Apps** from the main menu.
3. Select the app you wish to explore and start using it.

***

**Contributing Feedback**

As part of the Ofero Network community, SFT Holders and Verified Members play a vital role in refining beta applications. Feedback is encouraged to help improve usability and features.

* To submit feedback, contact the community via the Telegram Channel.
